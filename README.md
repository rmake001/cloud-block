# ☁️ CloudBlock

**Bringing the neighborhood block to the clouds.**

CloudBlock is a cloud-themed community app that transforms apartment buildings into vibrant, connected neighborhoods.

## 💭 Inspiration

Inspired by skyscrapers that bring neighbors closer to the clouds, both literally and figuratively, CloudBlock reimagines the traditional neighborhood block in the sky. Apartment buildings often lack the sense of community found in suburban neighborhoods, and we wanted to change that.

## ✨ Features

### 🏙️ Connect
Explore an interactive 3D skyscraper, discover neighbors through their windows, find shared interests, and make meaningful connections.

### ☁️ Contribute
Strengthen your community through a request-and-offer system where neighbors can ask for help, share resources, and give away items.

### 🪟 Your Window
Create a personalized window that represents you within your building, with privacy options to control what others see.

## 🛠️ Built With

- JavaScript

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/cloud-block.git
cd cloud-block
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.
